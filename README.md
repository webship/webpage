# Webpage

Provides a Webpage content type and related basic configurations.

Using the Display Builder by default. With a default body field for the base
page. The displays can be customized for selected advanced site section pages.

Helps site builder to structure web pages in the site.
 Linked in the main menu with nested site section path.

## Default recipe

`recipes/default` also includes the core content setup and a contact form:

- The Image, Datetime, Options, Menu link content, Menu UI and Views modules.
- The core content views (content, frontpage, archive, glossary, recent
  content, people, who's new and who's online), the large and thumbnail image
  styles and the compact user view mode.
- Webform and Webform UI, with a contact webform at `/form/contact`.
